# 004 — MCP: SDK e transporte

Data: 31/10/2026 · Situação: aceita

**Decisão.** SDK oficial `@modelcontextprotocol/sdk` (TypeScript). Servidor expõe uma
tool de busca por fonte e o host descobre as tools com `tools/list` antes de chamar.
Transporte **stdio** no experimento (sem rede no meio da medição); Streamable HTTP
opcional, só para a demonstração.

**Consequências.** A latência medida inclui serialização JSON-RPC e comunicação entre
processos, que precisa ser separada do custo da busca na análise.
