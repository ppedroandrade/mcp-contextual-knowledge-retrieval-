# Arquitetura do auth-service

## Visão geral

O auth-service autentica usuários e emite tokens de acesso para a API e o portal. O serviço é mantido pelo Time Plataforma e é implementado em Go 1.23. Faz parte da plataforma Orbital Billing.

## Dados e dependências

O auth-service persiste seus dados em PostgreSQL 16 (banco identity). Mudanças de esquema seguem o processo de migração revisada pelo time responsável.

## Confiabilidade

O objetivo de nível de serviço (SLO) do auth-service é 99,99% de disponibilidade mensal. Em falhas temporárias, a política de novas tentativas é: sem novas tentativas; tokens de acesso expiram em 15 minutos.
