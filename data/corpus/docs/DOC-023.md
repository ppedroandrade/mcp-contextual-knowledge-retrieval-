# Como habilitar login único (SSO)

## Quando usar

Use quando o cliente quiser que os usuários entrem no portal com o provedor de identidade da própria empresa.

## Passo a passo

1. Peça ao cliente o arquivo de metadados SAML do provedor de identidade.
2. Cadastre o arquivo em Configurações > Segurança > SSO.
3. Envie ao cliente a URL de ACS https://auth.orbital.example/saml/acs.
4. Teste o login com um usuário do cliente antes de tornar o SSO obrigatório.

## Limites e observações

O SSO via SAML 2.0 só está disponível no plano Enterprise. Não há suporte a OpenID Connect nesta versão.
