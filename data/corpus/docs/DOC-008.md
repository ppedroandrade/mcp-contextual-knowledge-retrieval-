# Arquitetura do customer-portal

## Visão geral

O customer-portal é o painel web em que os clientes gerenciam assinaturas, chaves e relatórios. O serviço é mantido pelo Time Web e é implementado em Next.js 15 com React 19. Faz parte da plataforma Orbital Billing.

## Dados e dependências

O customer-portal persiste seus dados em sem banco próprio; consome a billing-api e o auth-service. Mudanças de esquema seguem o processo de migração revisada pelo time responsável.

## Confiabilidade

O objetivo de nível de serviço (SLO) do customer-portal é 99,9% de disponibilidade mensal. Em falhas temporárias, a política de novas tentativas é: até 2 tentativas no cliente HTTP para chamadas idempotentes.
