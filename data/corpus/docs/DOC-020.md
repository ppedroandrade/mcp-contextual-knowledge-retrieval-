# Como usar o ambiente sandbox

## Quando usar

Use para testar integrações de cobrança sem movimentar dinheiro.

## Passo a passo

1. Gere uma chave de sandbox no portal.
2. Aponte as chamadas para https://sandbox.api.orbital.example.
3. Use os cartões de teste para simular aprovação e recusa.
4. Confira os eventos de webhook de teste no painel.

## Limites e observações

O cartão de teste 4000 0000 0000 0002 sempre simula uma recusa. Os dados do sandbox são apagados a cada 30 dias.
