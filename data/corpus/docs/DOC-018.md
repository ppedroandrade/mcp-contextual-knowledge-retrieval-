# Como configurar e validar webhooks

## Quando usar

Use quando o cliente precisar receber eventos como invoice.paid ou subscription.canceled no próprio sistema.

## Passo a passo

1. Cadastre a URL de destino em Configurações > Webhooks.
2. Selecione os eventos desejados.
3. Valide cada entrega conferindo a assinatura HMAC-SHA256 enviada no cabeçalho X-Orbital-Signature.
4. Responda com status 2xx para confirmar o recebimento.

## Limites e observações

O sistema do cliente precisa responder em até 5 segundos; acima disso a entrega é considerada falha e entra na política de novas tentativas.
