# Como mudar o plano de uma assinatura

## Quando usar

Use quando o cliente quiser fazer upgrade ou downgrade de plano.

## Passo a passo

1. Chame PATCH /v2/subscriptions/{id} com o novo plan_id.
2. Para upgrade, a diferença é cobrada na hora.
3. Para downgrade, a mudança fica agendada.
4. Confira o evento subscription.updated no webhook.

## Limites e observações

O upgrade é cobrado pró-rata no mesmo dia; o downgrade só passa a valer no próximo ciclo de cobrança, sem reembolso proporcional.
