# Como rotacionar uma chave de API

## Quando usar

Use este procedimento quando uma chave de API vazar, quando um colaborador com acesso sair da empresa cliente ou perto do vencimento da chave.

## Passo a passo

1. Acesse o portal e abra Configurações > Chaves de API.
2. Clique em "Gerar nova chave" e copie o valor exibido, que não será mostrado de novo.
3. Atualize a chave nos sistemas do cliente.
4. Revogue a chave antiga no mesmo menu.

## Limites e observações

As chaves de API expiram em 90 dias. Durante a rotação, a chave antiga e a nova funcionam juntas por até 24 horas.
