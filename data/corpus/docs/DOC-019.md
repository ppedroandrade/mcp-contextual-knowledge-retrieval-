# Limites de requisição da API

## Quando usar

Consulte quando o cliente receber respostas HTTP 429 (Too Many Requests).

## Passo a passo

1. Verifique o cabeçalho Retry-After da resposta 429.
2. Aguarde o tempo indicado antes de repetir a chamada.
3. Distribua as chamadas em lote ao longo do minuto.
4. Se o volume for permanente, solicite aumento de limite ao suporte.

## Limites e observações

O limite padrão é de 600 requisições por minuto por chave de API. Clientes Enterprise podem negociar até 3.000 requisições por minuto.
