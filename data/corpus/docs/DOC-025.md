# Como atualizar o SDK oficial para Node.js

## Quando usar

Use quando o cliente ainda usa uma versão antiga do SDK @orbital/billing.

## Passo a passo

1. Atualize com npm install @orbital/billing@latest.
2. Troque chamadas a client.invoices.list por client.invoices.search.
3. Rode os testes de integração do cliente no sandbox.
4. Publique a atualização.

## Limites e observações

A versão mínima suportada do SDK é a 4.2.0. A linha 3.x foi descontinuada em 30/06/2026.
