# Como reprocessar uma fatura com falha

## Quando usar

Use quando uma fatura ficar com status failed depois de um erro de geração.

## Passo a passo

1. Confirme que a fatura está com status failed.
2. Chame POST /v2/invoices/{id}/reprocess com a chave de API do cliente.
3. Acompanhe o status até mudar para issued.
4. Se falhar de novo, abra um chamado com o id da fatura.

## Limites e observações

Cada fatura aceita no máximo 3 reprocessamentos. Depois disso, a correção precisa ser feita pelo Time Faturamento.
